前撮りの準備は、撮影日の2〜3ヶ月前から始めれば間に合います。

やることは「衣装」「ヘアメイク」「肌と爪」「持ち物」の4つと、撮影までのお支払いや天気の確認です。

ロケ地を決めることや撮影の許可を取ることは、in the moment の側で引き受けています。

この記事では、名古屋・愛知で前撮りやフォトウェディングを予定しているふたりが、撮影日から逆算して何をいつ用意すればいいかをまとめました。

## 準備のスケジュール

| 時期 | やること |
| --- | --- |
| 予約したとき | 撮影契約書へのご署名・お申し込み金（総額の50%）のお振込み |
| 2〜3ヶ月前 | ロケ地とイメージの打ち合わせ・衣装を探しはじめる |
| 1〜2ヶ月前 | ヘアメイクの手配・アクセサリーや小物をそろえる |
| 1週間前 | 残金のお振込み・ブライダルエステはこのころまでに |
| 3〜5日前 | シェービング・新郎の髪のカット・天気予報を見はじめる |
| 前日 | ネイル・荷物をまとめる・天気の最終確認 |
| 撮影後 | 写真は約1ヶ月、ムービーを含むプランは約1.5ヶ月で納品 |

桜や紅葉など撮りたい季節が決まっているなら、その3ヶ月ほど前が動きはじめの目安です。

ウェルカムボードや年賀状に写真を使う予定があるなら、使いたい日から納品の期間を逆算して撮影日を決めておくと余裕が生まれます。

## 任せられること、ふたりが用意すること

| 区分 | 内容 |
| --- | --- |
| in the moment | ロケ地の提案と決定・撮影許可の申請・当日の進行・写真のカラーグレーディングやムービーの編集 |
| ふたり | 衣装・アクセサリー・靴・小物・当日の持ち物 |
| ヘアメイク | ヘアメイク付きのプランなら in the moment で手配し、当日も同行して撮影中のお直しまで。付けない場合は、ふたりで美容室を予約 |
| 実費 | 施設の撮影料や許可の費用がかかる場所のみ |

ロケ地の候補が浮かんでいなくても大丈夫です。

打ち合わせで好きな雰囲気や季節を伺いながら、一緒に決めていきます。

候補を眺めておきたい方は「[名古屋・愛知の前撮りロケ地10選](https://www.inthemoment.jp/journal/maedori-location-aichi-nagoya)」をどうぞ。

料金に含まれるものと別にかかるものは「[前撮りの費用と相場](https://www.inthemoment.jp/journal/38b00e997dfa81d89ecac94e73775fdb)」にまとめています。

## 衣装・服装

洋装（ウェディングドレス・タキシード）か和装（白無垢・色打掛・紋付袴）か、まずはふたりのイメージをそろえるところから始めます。

衣装はふたりでご用意いただく形です。

ブライダルショップやレンタルショップは試着とサイズ直しに時間がかかるので、撮影日の2〜3ヶ月前には相談を始めておくと安心です。

- アクセサリー（ピアス・ネックレス・ヘアアクセサリー）は衣装が決まってから合わせて選ぶ
- ドレスの下に着るインナーは型によって違うので、試着のときにお店で確認する
- 靴は長い時間歩いても痛くならないか、事前に履いて確かめておく

ドレスや着物でなく、お気に入りの私服で撮ることもできます。

私服で撮った実例と着こなしのコツは「[私服の前撮り・フォトウェディング](https://www.inthemoment.jp/journal/maedori-shifuku)」にまとめています。

## ヘアメイク

ヘアメイクは、in the moment のプランに含めることも、ご自身の美容室にお願いすることもできます。

写真・ムービーどのプランにもヘアメイクを付けられ、料金は¥55,000上がります。

たとえば写真のみのプランなら、¥100,000が¥155,000になります。

当日はヘアメイクがつきっきりで同行するので、ロケーションの移動や風で崩れた髪もその場で直せます。

ご自身で美容室を手配する場合は、撮影日の1〜2ヶ月前に予約を入れておくと安心です。

どちらの場合も、なりたい髪型の画像が数枚あると仕上がりの相談がしやすくなります。

撮影そのものの雰囲気は、参考写真のリストではなく打ち合わせの言葉で伺っています。

当日の光や場所に合わせて撮り方を決めていくためです。

ムービーを含むプランなら、好きな曲や音楽の雰囲気もいくつか考えておいてください。

## 新郎の準備

新郎の支度は、新婦にくらべて軽く考えられがちです。

けれど写真にはふたりが並んで写ります。

- スーツやタキシードの手配は2〜3ヶ月前（レンタルはサイズ直しの期間も見込んで）
- シャツ・ネクタイ・ベルト・靴下・靴は、色の合わせまで前もって確認
- 髪は撮影の3〜5日前にカット（切りたてより数日おいたほうがなじみます）
- ひげは剃り跡が残らないよう当日の朝に
- 眉を整えておくと、顔まわりの印象が変わります

和装なら、紋付袴の小物（羽織紐・雪駄・足袋）がそろっているかを衣装の受け取りのときに確かめておくと安心です。

かっちりしたタキシードでなくても大丈夫です。

ネクタイを締めないシャツにジャケット、ニットなど、ふだんに近い装いでも撮影できます。

## 肌と爪の準備

前撮りの写真には、手元がよく写ります。

指輪をつけた指も、ブーケを支える手も、そのまま残ります。

- シェービングは肌が落ち着く撮影の3〜5日前に
- ブライダルエステを受けるなら、直前ではなく1週間ほど前に
- ネイルは前日までに（当日は乾く時間が読めません）
- 日焼けが気になる季節は、1〜2週間前から日差しを避ける
- 手荒れしやすい季節は、数日前からハンドクリームを

睡眠と水分も、当日の肌のためにできる準備のひとつです。

## 天気と予定の変更

撮影日の3日前ごろから、天気予報を一緒に見はじめます。

前日の夜から当日の朝にかけてLINEで連絡を取りながら、撮影するかどうかを最終的に決めます。

小雨なら撮影できることも多く、大雨や雷、台風が予想されるときは延期します。

天候による延期は1回まで無料です。

ご都合で日にちを変えたいときは、撮影日の3日前までに連絡をいただければ1回目は無料で変更できます。

## 当日の持ち物チェックリスト

屋外のロケーションでは、支度から撮影の終わりまで半日ほどかかります。

季節と天気で足すものが変わるので、迷ったら持っていくほうが安心です。

| 区分 | 持ち物 |
| --- | --- |
| 基本 | [ ] 衣装一式<br>[ ] 化粧直し用のポーチ<br>[ ] ティッシュ・コットン<br>[ ] 飲み物・軽食<br>[ ] 常備薬 |
| 新郎 | [ ] シャツ・ネクタイ・ベルト<br>[ ] 靴下・靴<br>[ ] 整髪料・あぶらとり紙<br>[ ] 替えのインナー |
| 夏 | [ ] 汗拭きシート<br>[ ] 携帯扇風機・扇子<br>[ ] 日焼け止め<br>[ ] 虫除け |
| 冬 | [ ] 使い捨てカイロ<br>[ ] 厚手のストール<br>[ ] 羽織るもの |
| 雨の日 | [ ] 透明傘<br>[ ] 替えの靴・靴下<br>[ ] タオル |

衣装はしわにならないよう、ガーメントバッグか大きめの箱に入れて運びます。

飲み物は、口紅がつきにくくドレスも汚しにくいストロー付きのボトルが便利です。

雨の日の傘は透明なものにすると、写真に入っても景色の色が変わりません。

花束や指輪、手紙など、撮影に添える小物のアイデアは「[前撮りの小物・アイテムのアイデア](https://www.inthemoment.jp/journal/39600e997dfa81818acec9d496bd0b57)」にまとめています。

## 前日にやること

- [ ] 荷物をすべてまとめて、玄関に置いておく
- [ ] 衣装・アクセサリー・インナー・靴がそろっているか確認する
- [ ] 新郎の一式もあわせて確認する
- [ ] 集合場所・時間・移動の経路を確認する
- [ ] 夜はよく眠り、食べすぎ・飲みすぎを避ける

遅れて着いた場合も、撮影の終わりの時間は変わりません。

移動には少し余裕をみておいてください。

当日の時間ごとの動きは「[前撮り当日の流れ](https://www.inthemoment.jp/journal/39600e997dfa81c3bb1fef5b4bc2d83a)」にまとめています。

すべてを完璧にそろえる必要はありません。

わからないことは、打ち合わせやLINEでその都度一緒に整えていきます。
