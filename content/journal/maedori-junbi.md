前撮りの準備は「衣装」「ヘアメイク」「肌と爪」「持ち物」「ふたりで決めておくこと」の5つに分けて考えると迷いません。

動き始めの目安は、撮影日の2〜3ヶ月前です。

名古屋・愛知でロケーション前撮り・フォトウェディングを撮ってきた経験から、当日までに必要なものをこの1本にまとめました。

## 準備のスケジュール

| 時期 | やること |
| --- | --- |
| 3ヶ月前 | 季節とロケーションのイメージを決める |
| 2〜3ヶ月前 | 衣装を探す（新郎のスーツもこの時期に） |
| 1〜2ヶ月前 | ヘアメイクの手配・小物の準備 |
| 3〜5日前 | シェービング・新郎の髪を切る |
| 前日 | ネイル・持ち物をまとめる |
| 撮影後 | 写真は4週間、ムービーを含むプランは6週間ほどで納品 |

桜や紅葉など撮りたい季節があるなら、その季節が来る3ヶ月ほど前が動き出しの合図です。

結婚式のウェルカムボードや年賀状に使う予定があるなら、使いたい日から2ヶ月ほど遡って撮影日を決めておくと余裕が生まれます。

## 衣装・服装の準備

洋装（ウェディングドレス / タキシード）か和装（白無垢 / 色打掛 / 紋付袴）か、まずはふたりのイメージをすり合わせておくとスムーズです。どちらも試着してから決めたい場合は、撮影日の2〜3ヶ月前には動き始めるのが理想です。

衣装はご自身でご準備いただく形になります。ブライダルショップやレンタルショップで手配する場合は、早めのご確認をおすすめします。

- アクセサリー（ピアス・ネックレス・ヘアアクセサリー）は衣装が決まったら合わせて選んでおく
- インナーはドレスの型によって異なる。試着時に店舗スタッフに確認しておくと安心
- 靴はヒールの高さも含め、長時間履けるか事前に試し履きをしておく
- 着替え

衣装はドレスや着物でなくても大丈夫です。

お気に入りの私服や、ふたりらしいラフなスタイルで臨んでいただくこともできます。

私服で撮った実例と着こなしのコツは「[私服での前撮りという選択](https://www.inthemoment.jp/journal/maedori-shifuku)」にまとめています。

ブーケを一束添えるだけで、どんな服装も不思議とシックに見えます。

ベールを纏えば、より特別な一日の空気感が生まれます。

「この服で大丈夫かな」と思ったときは、気軽にご相談ください。

## ヘアメイク

ヘアメイクはin the momentでご手配することも、ご自身の美容室にお願いすることも可能です。

in the momentにお任せの場合：打ち合わせの際にご希望のスタイルをお伝えください。参考画像があるとよりスムーズです。

ヘアメイクは当日つきっきりのアテンド付きなので、ロケーションの移動や風で崩れたヘアもその場でお直しできます。

ご自身で美容室を手配する場合：撮影日の1〜2ヶ月前を目安に予約を入れておくと安心です。前撮り経験のあるサロンに相談するのもおすすめです。

どちらの場合も、イメージ画像を数枚まとめておくと当日の仕上がりが共有しやすくなります。

- 仕上げのイメージ画像を数枚まとめておく（PinterestやInstagramのスクショが便利）
- 気になることはどんな些細なことでも事前にご相談ください

## 新郎の準備

新郎の支度は、新婦にくらべて手軽に考えられがちです。

けれど写真にはふたりが並んで写ります。

襟の形も靴の艶も、同じだけ残ります。

- スーツ・タキシードの手配は2〜3ヶ月前（レンタルは試着とサイズ直しの期間も見込んで）
- シャツ・ネクタイ・ベルト・靴下・靴は、当日の色合わせまで含めて前もって確認
- 髪は撮影の3〜5日前にカット（切りたてより数日おいたほうが馴染みます）
- ひげは剃り跡が残らないよう当日の朝に
- 眉のかたちを整えておくと、顔まわりの印象が変わります

和装の場合は、紋付袴の小物（羽織紐・雪駄・足袋）が揃っているかを、衣装の受け取り時にひととおり確認しておくと安心です。

## 肌と爪の準備

前撮りの写真には、手元がよく写ります。

指輪をつけた指、ブーケを支える手、そっと重ねたふたりの手。

- ネイルは前日までに（当日は乾く時間が読めません）
- シェービングは肌が落ち着く3〜5日前が目安
- ブライダルエステを受ける場合も、直前ではなく1週間ほど前に
- 手荒れが気になる季節は、数日前からハンドクリームを

日焼けが気になる季節は、撮影の1〜2週間前から日差しを避けておくと安心です。

睡眠と水分も、当日の肌のためにできる準備のひとつです。

## 前撮り当日の持ち物チェックリスト

屋外ロケーションの場合、準備から片付けまで含めると数時間かかることが多いです。

季節と天気で足すものが変わります。多少荷物が増えても、迷ったら持っていくほうが当日は安心です。

| 区分 | 持ち物 |
| --- | --- |
| 基本 | [ ] 衣装一式<br>[ ] 化粧直し用ポーチ<br>[ ] ティッシュ・コットン<br>[ ] 飲み物・軽食<br>[ ] 常備薬<br>[ ] 防寒グッズ<br>[ ] 折りたたみ傘 |
| 新郎 | [ ] シャツ・ネクタイ・ベルト<br>[ ] 靴下・靴<br>[ ] 整髪料・あぶらとり紙<br>[ ] 替えのインナー |
| 夏 | [ ] 汗拭きシート<br>[ ] 携帯扇風機・扇子<br>[ ] 日焼け止め<br>[ ] 虫除け |
| 冬 | [ ] 使い捨てカイロ<br>[ ] 厚手のストール<br>[ ] 羽織るもの |
| 雨の日 | [ ] 透明傘<br>[ ] レインカバー<br>[ ] 替えの靴・靴下<br>[ ] タオル |

衣装はしわにならないよう、ガーメントバッグか大きめの箱に入れて運びます。

飲み物はドレスを汚しにくいストロー付きのボトルが安心です。

雨の日の傘は、透明なものを。色が入らないので、写真に写り込んでも景色がそのまま残ります。

## 事前にふたりで決めておくこと

撮影前にふたりで確認しておきたいことをまとめました。当日の流れを把握しておくと、気持ちにゆとりが生まれます。

- [ ] ロケーション（屋外・屋内・複数場所の組み合わせ。悪天候時の希望もあわせて）
- [ ] 雰囲気のイメージ（ナチュラル・クラシック・フィルム感など。参考写真を複数集めておく）
- [ ] 当日のタイムスケジュール（集合時間・撮影終了の目安・移動ルートを事前に確認）
- [ ] ネイルが必要な場合は前日までに
- [ ] 小道具や演出アイテム（花束・ドライフラワーなどを持参する場合は事前にご相談を）
- [ ] ムービーを撮る場合はどんな音楽で作りたいか（好きな曲・雰囲気のイメージをいくつか）

小物選びは「[前撮りの小物・アイテムのアイデア](https://www.inthemoment.jp/journal/39600e997dfa81818acec9d496bd0b57)」に、当日の動きは「[前撮り当日の流れ](https://www.inthemoment.jp/journal/39600e997dfa81c3bb1fef5b4bc2d83a)」に詳しくまとめています。

## 前日にやること

- [ ] 荷物をすべてまとめて、玄関に置いておく
- [ ] 衣装・アクセサリー・インナー・靴の忘れ物チェック
- [ ] 新郎の一式もあわせて確認（意外と当日の朝に探すことになりがちです）
- [ ] 翌日の集合場所・時間・移動経路を確認しておく
- [ ] 十分な睡眠をとる（むくみ・くすみ予防）
- [ ] 過度な飲食は避け、顔や体のコンディションを整える

準備といっても、すべてを完璧にそろえる必要はありません。

わからないことはその都度、打ち合わせやLINEで一緒に整えていきましょう。

撮影の日は、ふたりの時間を楽しむことだけ考えていられるように。
